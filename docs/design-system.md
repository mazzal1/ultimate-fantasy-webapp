# Design System

## Theme tokens

- Primary: `#4A1D96`
- Secondary: `#D97706`
- Background: `#0D0A1E`
- Surface: `#1A1533`
- Text: `#F3F0FF`
- Error: `#DC2626`
- Success: `#059669`

## Typography

- Headings use a system serif stack.
- Body copy uses a system sans-serif stack.

## Component rules

- Use inline style objects.
- Prefer shared token imports over ad hoc colors.
- Keep cards, buttons, inputs, and badges visually consistent.
